# Сборка приложения «Библиотека» под Android

Код на Kivy кроссплатформенный: тот же проект собирается в .apk через buildozer.
В инструкции два варианта: **облачная сборка через GitHub** (не нужны права
администратора — рекомендуется) и **локальная сборка через WSL** (нужен
пароль администратора).

## Что добавлено в проект для Android

| Файл | Назначение |
|---|---|
| `main.py` (в корне) | входная точка для сборки apk (на ПК запускайте `Main/main.py` как раньше) |
| `buildozer.spec` | настройки сборки |
| `Db/__init__.py`, `Main/__init__.py` | делают папки пакетами — так надёжнее для Android |

## Тексты книг

Кладите файлы `Main/books/1.txt`, `Main/books/2.txt`, ... (кодировка UTF-8, абзацы
разделяются пустой строкой). При следующем запуске текст подхватится автоматически —
и на ПК, и в собранном apk (папка копируется внутрь apk).

## Вариант А (без прав администратора): сборка в облаке через GitHub

GitHub бесплатно собирает apk на своём сервере — ничего устанавливать не нужно,
нужен только аккаунт на github.com. Файл `.github/workflows/build-android.yml`
уже создан в проекте: после отправки кода сборка запускается сама.

### Шаг 1. Создать аккаунт и репозиторий

1. Зарегистрируйтесь на https://github.com (нужна только электронная почта).
2. Нажмите **New repository**, имя — например `library`, выберите **Private**
   (частный репозиторий), галочку «Add a README» не ставьте.

### Шаг 2. Отправить код на GitHub

Откройте Git Bash (Пуск → Git Bash) и выполните:

```
cd /c/Users/student.DULATY.000/PycharmProjects/PythonProject7
git remote add origin https://github.com/ВАШ_ЛОГИН/library.git
git push -u origin main
```

При первой отправке откроется окно входа в GitHub — войдите в аккаунт.

### Шаг 3. Получить apk

1. Откройте свой репозиторий на github.com → вкладка **Actions**.
2. Запустится сборка «Build Android APK» (жёлтый кружок). Первый раз
   занимает 20–40 минут.
3. Когда появится зелёная галочка — откройте запуск, внизу раздел
   **Artifacts** → `library-apk` → скачается zip с файлом .apk.
4. Перекиньте apk на телефон и установите (разрешите установку из
   неизвестных источников).

### После изменений кода

```
cd /c/Users/student.DULATY.000/PycharmProjects/PythonProject7
git add .
git commit -m "описание изменений"
git push
```

Сборка запустится сама, новый apk появится в Artifacts. Для частного
репозитория бесплатно даётся 2000 минут сборок в месяц — одна сборка
занимает около 30 минут, этого хватит с запасом.

## Вариант Б (нужен пароль администратора): локальная сборка через WSL

### Шаг 1. Установить WSL (один раз)

1. Откройте PowerShell **от имени администратора** и выполните:
   ```
   wsl --install -d Ubuntu
   ```
2. Перезагрузите компьютер.
3. После перезагрузки откроется Ubuntu — придумайте имя пользователя и пароль
   (пароль при вводе не отображается, это нормально).

## Шаг 2. Подготовить Ubuntu (один раз)

Откройте Ubuntu (меню «Пуск» → Ubuntu) и выполните:

```
sudo apt update
sudo apt install -y git zip unzip openjdk-17-jdk python3-venv autoconf libtool \
    pkg-config zlib1g-dev libncurses5-dev libncursesw5-dev libffi-dev libssl-dev

python3 -m venv ~/buildozer-venv
source ~/buildozer-venv/bin/activate
pip install buildozer
```

`source ~/buildozer-venv/bin/activate` нужно повторять в каждом новом окне Ubuntu
(в начале строки появится приставка `(buildozer-venv)`).

## Шаг 3. Скопировать проект внутрь WSL

Сборка напрямую с диска C: работает очень медленно, поэтому копируем проект
в домашнюю папку Ubuntu:

```
mkdir -p ~/library
cd /mnt/c/Users/student.DULATY.000/PycharmProjects/PythonProject7
cp -r Main Db main.py buildozer.spec ~/library/
cd ~/library
```

## Шаг 4. Собрать apk

```
buildozer android debug
```

- Первый запуск скачивает Android SDK/NDK и собирает Python + Kivy — занимает
  30–60 минут и ~10 ГБ на диске.
- Готовый файл появится в `~/library/bin/` (например
  `library-0.1-arm64-v8a-armeabi-v7a-debug.apk`). Подходит для телефонов
  с Android 5.0 и новее.

## Шаг 5. Установить на телефон

1. В Проводнике Windows откройте `\\wsl$\Ubuntu\home\<ваш_логин>\library\bin`
   (или скопируйте apk оттуда на рабочий стол).
2. Перекиньте apk на телефон (USB, Telegram, облако).
3. На телефоне откройте apk и разрешите установку из неизвестных источников.

## После изменений кода

Повторите шаги 3–4: скопируйте свежие файлы в `~/library` и снова выполните
`buildozer android debug` (повторные сборки идут намного быстрее первой).

## Если что-то пошло не так

- **git push выдаёт `schannel: CRYPT_E_NO_REVOCATION_CHECK` или похожую ошибку
  про сертификат** — школьная/корпоративная сеть перехватывает HTTPS. На этом
  компьютере уже настроен обход: SSH-ключ + `~/.ssh/config` (порт 443).
  Просто пользуйтесь `git push` — он идёт по SSH и не затрагивается этой
  проблемой. На новом компьютере настройку придётся повторить.
- **Пакет не найден (например, libtinfo5)** — уберите его из команды apt,
  он не всегда нужен.
- **Ошибка нехватки памяти (OOM / Killed)** — закройте лишние программы; если
  не помогло, создайте файл `C:\Users\student.DULATY.000\.wslconfig` со строками:
  ```
  [wsl2]
  memory=6GB
  ```
  и перезапустите Ubuntu (команда `wsl --shutdown` в PowerShell, затем снова
  откройте Ubuntu).
- **Сборка падает с «license is not accepted» или «Aidl not found»** — лицензии
  Android SDK не приняты. В облачной сборке это решается автоматически
  (шаг «Принять лицензии Android SDK» в workflow).
- **Сборка сломалась после изменений** — выполните `buildozer android clean`,
  потом снова `buildozer android debug` (полная пересборка).
- Подробный лог сборки выводится прямо в терминал (мы установили log_level = 2).
